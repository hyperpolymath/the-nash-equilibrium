== Tech Stack

Idris2 (ABI), Zig (FFI), ReScript (UI)

== Set Up Development Environment

=== Option A: mise (preferred)

[source,bash]
----
git clone https://github.com/hyperpolymath/the-nash-equilibrium.git
cd the-nash-equilibrium
mise install        # toolchain per mise.toml
----

=== Option B: direnv + asdf

[source,bash]
----
direnv allow        # loads .envrc (asdf/guix hooks, project env)
----

=== Option C: Dev container

Open the repository in an editor with devcontainer support
(`.devcontainer/devcontainer.json`).

=== Option D: Manual

Install the toolchain named in `mise.toml` / `.tool-versions` yourself,
then run `just doctor` to verify.

== Project Structure

[source]
----
the-nash-equilibrium/
├── src/                  # Source code
├── src/interface/abi/    # Idris2 ABI definitions
├── tests/                # Test suite
├── docs/                 # Documentation
├── .machine_readable/    # Checkpoint files (STATE, META, ECOSYSTEM)
├── Justfile              # Task runner recipes
├── mise.toml             # toolchain manifest (mise)
├── .envrc                # direnv hooks
└── 0-AI-MANIFEST.a2ml    # AI agent entry point
----

== Key Recipes

[source,bash]
----
just build          # Build the project
just test           # Test suite recipe
just doctor         # Self-diagnostic
just lint           # Lint and format
just quality        # fmt-check + lint + docs-check + test
just tour           # Guided tour of the codebase
----

== Before Submitting a PR

[source,bash]
----
just lint           # Format and lint
just test           # Test suite passes
just e2e            # End-to-end pipeline (tests/e2e.sh)
----
