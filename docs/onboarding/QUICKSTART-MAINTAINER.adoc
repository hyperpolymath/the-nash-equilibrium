== Overview

This guide covers packaging, deploying, and maintaining the-nash-equilibrium for
distribution on your platform.

== Runtime Dependencies

idris2, zig, deno

== Build from Source

[source,bash]
----
git clone https://github.com/hyperpolymath/the-nash-equilibrium.git
cd the-nash-equilibrium
just build-release
----

Output: `build/`

== Packaging

=== Container

[source,bash]
----
podman build -f container/Containerfile -t the-nash-equilibrium .
----

=== Manual Package

[source,bash]
----
just install --prefix=/usr/local
----

Files installed:

[cols="1,2"]
|===
| Path | Contents

| `$PREFIX/bin/`
| Executables

| `$PREFIX/share/the-nash-equilibrium/`
| Data files, assets

| `$PREFIX/share/doc/the-nash-equilibrium/`
| Documentation

| `$PREFIX/share/applications/`
| .desktop file (Linux, if GUI)

| `$PREFIX/share/man/man1/`
| Man pages
|===

== Configuration

Default config location: `$XDG_CONFIG_HOME/the-nash-equilibrium/config.toml`

Fallback: `$HOME/.config/the-nash-equilibrium/config.toml`

== Health Checks

[source,bash]
----
just doctor            # Full diagnostic
just run --version   # Version check
just run --selftest  # Built-in self-test
----

== Updating

[source,bash]
----
git pull
just build-release
just install --prefix=/usr/local
----

Or via OPSM: `opsm update the-nash-equilibrium`

== Multi-Instance Deployment

For deploying multiple instances (e.g., different users or tenants):

[source,bash]
----
just install --prefix=/opt/the-nash-equilibrium-instance1 --config=/etc/the-nash-equilibrium/instance1.toml
just install --prefix=/opt/the-nash-equilibrium-instance2 --config=/etc/the-nash-equilibrium/instance2.toml
----

Each instance has isolated config, data, and logs.
